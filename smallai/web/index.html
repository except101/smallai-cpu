    开始第一次训练

    1. 打开「数据与题库」，选择题库文件，检查预览后点击「导入并准备训练」。也可以获取公开数据。
    2. 有自己的模型权重时，沿用它的分词器导入题库，选择「问答与工具调用训练」。首次使用则建立新分词器，先做「从零预训练」。
    3. 选择数据和步数，点击「开始训练」。进度、loss、速度和日志实时更新。
    4. 点击「停止并保存」可提前结束；稍后点击「继续训练」完成剩余步数。

    建议题库包含至少 20 道不同题目。超出 1024 token 的完整问答会跳过并显示数量。100% 表示计划步数完成，模型能力需单独评测。

    题库文件与权重保存在本机，不会随代码上传 GitHub。新分词器需从零预训练；沿用分词器才可以使用已有权重。
