开始第一次训练

  1. 在「公开训练数据」点击获取数据，或直接选择已经准备好的公开数据。
  2. 选择「从零预训练」，点击「开始训练」。进度、loss、速度和日志会实时更新。
  3. 想提前结束时，点击「停止并保存」；稍后可继续同一份训练计划。
  4. 预训练完成后，选择使用相同分词器的对话与工具数据，以及刚保存的权重。

公开数据下载的是适合本机试训的子集。进度 100% 表示计划步数完成，模型能力需单独评测。函数调用数据用于学习工具选择和参数，实际执行仍限于本地已注册工具。

每份公开数据配套新的分词器。示例数据、旧权重和以前的训练记录都会保留。
